**Owner gate:** Brandon approves this spec and resolves D1–D5 before plan/tasks are handed to an implementer. The spec owner (Claude/Brandon) performs spec-status transitions separately; the implementer does not edit this spec.

## Problem and outcome
As a new developer or Brandon returning to Field Closeout, I want an accurate one-page setup guide and current handoff state, so that I can go from a clean clone to a passing local `bun run verify` using the README alone and can distinguish the live hosted demo from the last revision backed by full Phase 1 verification evidence.

The README currently contains only the project name, while `docs/handoffs/CURRENT.md` still lists hosted-demo deployment as a future action even though `https://field-closeout.vercel.app` is live at `main@5925540` in `hosted_demo`. The refresh must correct that operational picture without erasing Phase 1 history, inventing test evidence, or unblocking the Phase 2 real-data pilot.
